# 🛢️ Barriles del Amor ❤️

Un mini-juego arcade inspirado en el clásico del **gorila y el plomero saltador** (Donkey Kong). Trepa las plataformas esquivando los barriles que lanza el gorila 🦍... y cada vez que **pierdes una vida**, aparece una **penitencia** que tu novia te debe a ti 😈❤️.

## Cómo jugar

Abre `index.html` en cualquier navegador (PC o móvil).

- **PC:** `←` `→` para moverte, `↑` o `Espacio` para saltar, `↑`/`↓` para trepar escaleras.
- **Móvil:** botones táctiles en pantalla (◀ ▶ y SALTO).

Sube hasta arriba para pasar de nivel. Cada nivel los barriles van más rápido.

## Penitencias personalizables

Pulsa **✏️ Editar penitencias** en la pantalla de inicio para poner las tuyas (una por línea). Se guardan en el navegador de ese dispositivo.

## Detalles

- Un solo archivo HTML, sin dependencias ni internet.
- Funciona offline.
